# Vocabulary for test data and documentation examples.
#
# This repository is public; the developer's real library is not. Test data is
# therefore *declared* rather than improvised: anything that looks like content
# -- a path with separators, a media filename, any CJK text -- has to be built
# from the names below, and tools/check-private.py enforces it.
#
# The point is the failure mode it catches. A denylist can only stop names
# someone remembered to list; this stops the work title nobody knew about,
# which is the case that kept slipping through.
#
# Adding to this file is expected and cheap. What is not allowed is quietly
# pasting a name off a device log. If a new name is needed, invent one and put
# it here -- the declaration is the review.
#
# Lines starting with ~ are regular expressions matched against a whole literal
# or a single path segment. Everything else is an exact path segment or file
# name. `#` starts a comment.

# Names whose shape is the subject of the test (natural sort, paging), where
# the digits are the point and carry nothing else.

~^[0-9]+([.-][0-9]+)*\.(jpg|png)$
~^chapter[0-9]+_page[0-9]+\.jpg$
